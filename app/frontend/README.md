# Frontend

Next.js 14 (App Router) + TypeScript + Tailwind + Three.js / R3F + Framer Motion.

See `../DOCS/ARCHITECTURE.md` for the full system design.

## Scripts

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
npm run typecheck
```

## Environment

Copy `.env.local.example` to `.env.local` and set `NEXT_PUBLIC_API_BASE_URL` to the backend service URL.
